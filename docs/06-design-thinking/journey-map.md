# سفر کاربر: ۳۰ روز اول

**نسخه:** ۱.۰ · **مرحله:** ۶ از ۱۳ (تفکر طراحی) · **قدم:** ۳ از ۷

> علامت 🔬 یعنی حدس درباره‌ی احساس یا رفتار که از داده نیومده. علامت ❓ یعنی تصمیمی که با طراح محصوله.

---

## ۱. خلاصه

سفر **آرش، شروع‌کننده‌ی رهاکننده** ([پرسوناها](personas.md))، از لحظه‌ای که تصمیم می‌گیره عادتی بسازه تا روز ۳۰ و بعدش. آرش انتخاب شده چون پرریسک‌ترین مسیر رو داره: پرسشنامه نشون داد بیشترین رها کردن در **هفته‌ی دوم و سوم** و **بعد از اولین جا انداختن** اتفاق می‌افته.

تفاوت‌های **نگار** (ردیاب کاغذی) و **مهدی** (۳۵+) در هر مرحله کنارش اومده.

**یازده مرحله:**

| ۲ | پیدا کردن و نصب | روز ۰ |
| ۳ | آنبوردینگ و ثبت‌نام | روز ۰ |
| ۴ | ساخت سؤال اول | روز ۰ |
| ۵ | اجازه‌ها و راهنمای باتری | روز ۰ |

| ۱۱ | مدال ۲۱ و ۳۰ و ماه تازه | روز ۲۱ تا ۳۰+ |

## ۳. مرحله‌به‌مرحله

### ۱. جرقه (قبل از نصب)

| | |
|---|---|
| **کار آرش** | در یک نقطه‌ی شروع (شنبه، اول ماه، نوروز، مهر) تصمیم می‌گیره دوباره ورزش کنه |
| **فکر** | «این بار فرق داره.» |
| **احساس** | امید و انرژی (۴) 🔬 |
| **درد** | تجربه‌ی شکست‌های قبلی: «باز هم ول می‌کنم؟» |
| **فرصت** | پیام کمپین روی همین نقطه‌ها (Dai و همکاران، ۲۰۱۴)؛ کمپین اول با ورزش و تغذیه |
| **ویژگی دیدیت** | کمپین نوروز با ورزش (D-008)؛ کارنامه‌ی قابل اشتراک کاربرهای دیگه |
| **نگار / مهدی** | نگار یک دفتر تازه می‌خره 🔬 / مهدی تصمیم رو به «بعد از این پروژه» موکول می‌کنه 🔬 |

### ۲. پیدا کردن و نصب (روز ۰)

| | |
|---|---|
| **کار آرش** | در کافه‌بازار «عادت» رو جست‌وجو می‌کنه یا تبلیغ داخل بازار رو می‌بینه (D-046) |
| **فکر** | «اینم یه اپ دیگه‌ست که ولش می‌کنم؟» |
| **احساس** | کنجکاوی همراه با تردید (۳) |
| **درد** | فهرست پر از اپ‌های شبیه هم؛ روتینو اول جست‌وجوئه |
| **فرصت** | پیام تمایز: «جای دفتر عادت‌هات» ([آنالیز رقبا](../05-competitors/competitor-analysis.md#پیام-تمایز)) |
| **ویژگی دیدیت** | صفحه‌ی فروشگاه و ASO (مرحله‌ی ۱۳) |

### ۳. آنبوردینگ و ثبت‌نام (روز ۰)

| | |
|---|---|
| **کار آرش** | صفحه‌های معرفی، شماره موبایل و کد پیامکی، نام کاربری و رمز (D-020، D-044)، انتخاب کرکتر شروع |
| **فکر** | «چرا شماره‌م رو می‌خواد؟»؛ «چقدر طول می‌کشه؟» |
| **احساس** | **بی‌حوصلگی و نگرانی (۲)** |
| **درد** | ثبت‌نام قبل از دیدن ارزش؛ قدم اضافه‌ی نام کاربری؛ نگرانی حریم خصوصی |
| **فرصت** | یک جمله درباره‌ی دلیل شماره و اینکه سؤال‌ها خصوصی‌ان؛ کوتاه نگه داشتن کل مسیر |
| **ویژگی دیدیت** | آنبوردینگ ۲ تا ۳ صفحه؛ معرفی فریز روی «خیر» در یک جمله (D-052) |
| **نگار / مهدی** | نگار اگه طول بکشه برمی‌گرده سراغ دفتر / مهدی حوصله‌ی رمز تازه ساختن نداره 🔬 |
| **ریسک** | فرضیه‌ی P1 (ریزش در ثبت‌نام) در پرسشنامه سنجیده نشد؛ در بتا سنجیده می‌شه 🔬 |

### ۴. ساخت سؤال اول (روز ۰)

| | |
|---|---|
| **کار آرش** | دسته‌ی ورزش، قالب «امروز ۲۰ دقیقه پیاده‌روی کردی؟»، روزها، ساعت یادآوری، «بعد از چی؟» (D-045)، «چرا برات مهمه؟» (D-052) |
| **فکر** | «چه ساده.» |
| **احساس** | رضایت (۴) |
| **درد** | انتخاب هدف خیلی بزرگ («هر روز یک ساعت ورزش»)؛ فیلدهای زیاد |
| **فرصت** | قالب‌های **کوچیک**؛ فیلدهای اختیاری جمع‌شده؛ کل کار زیر یک دقیقه |
| **ویژگی دیدیت** | قالب‌های آماده‌ی هر دسته ([درخت دسته‌ها](category-tree.md)) |

### ۵. اجازه‌ها و راهنمای باتری (روز ۰)

| | |
|---|---|
| **کار آرش** | اجازه‌ی نوتیفیکیشن، اجازه‌ی «آلارم و یادآوری» (اندروید ۱۲ به بعد)، راهنمای باتری مخصوص سامسونگ یا شیائومی |
| **فکر** | «این همه تنظیمات برای چی؟» |
| **احساس** | **کلافگی (۲)** |
| **درد** | چند صفحه‌ی تنظیمات سیستم؛ نفهمیدن دلیلش |
| **فرصت** | هر اجازه با یک جمله‌ی دلیل («تا سؤالت سر ساعت برسه»)؛ تست یادآوری همون لحظه |
| **ویژگی دیدیت** | ترتیب اجازه‌ها ([تحقیق کتابخانه‌ای](../04-research/desk-research.md#۸-نوتیفیکیشن-روی-اندروید-h4))؛ هشدار ملایم در صفحه‌ی اصلی اگه اجازه نداد |

### ۶. هفته‌ی اول (روز ۱ تا ۷)

| | |
|---|---|
| **کار آرش** | سر ساعت نوتیفیکیشن میاد؛ از روی خود نوتیفیکیشن «بله» می‌زنه |
| **فکر** | «این بار داره جواب می‌ده.» |
| **احساس** | **خوشحالی (۵)** |
| **درد** | اگه یادآوری نیاد (بستن اپ در پس‌زمینه)، اعتماد از دست می‌ره |
| **فرصت** | پاداش فوری و کوچیک: جشن کرکتر، XP، سطح ۲ در روز ۲ |
| **ویژگی دیدیت** | حلقه‌ی زیر ۱۰ ثانیه (اصل ۲)؛ ویجت |
| **نگار / مهدی** | نگار هر شب درصد پایبندی رو نگاه می‌کنه / برای مهدی رسیدن یادآوری مهم‌ترین چیزه |

### ۷. مدال ۷ روز (روز ۷)

| | |
|---|---|
| **کار آرش** | اولین مدال رو می‌گیره |
| **احساس** | **افتخار (۵)** |
| **فرصت** | کارنامه‌ی قابل اشتراک؛ نشون دادن هدف بعدی: «۱۴ روز تا مدال ۲۱» |
| **ویژگی دیدیت** | مدال ۷ (D-038)؛ XP ‎+۵۰ |

### ۸. منطقه‌ی خطر (روز ۸ تا ۲۰)

| | |
|---|---|
| **کار آرش** | هفته‌ی شلوغ کاری؛ نوتیفیکیشن‌ها تکراری شدن؛ گاهی دیر جواب می‌ده |
| **فکر** | «امروز وقت ندارم.» |
| **احساس** | **خستگی (۲)** |
| **درد** | تموم شدن تازگی؛ فاصله‌ی زیاد تا مدال بعدی (۷ تا ۲۱) |
| **فرصت** | متن چرخشی نوتیفیکیشن (D-045)؛ پیشرفت قابل‌دیدن («۳ روز تا مدال ۲۱»)؛ چیز تازه برای باز شدن (کرکتر در سطح ۵ حدود روز ۱۴) |
| **ویژگی دیدیت** | خلاصه‌ی هفتگی؛ شمارنده‌ی همراهان |
| **شاهد** | ۳۰٪ پرسشنامه عادت رو ۱ تا ۳ هفته ادامه دادن ([نتایج](../04-research/survey-results.md)) |

### ۹. اولین «خیر» یا جا انداختن

| | |
|---|---|
| **کار آرش** | **حالت الف:** «خیر» می‌زنه. **حالت ب:** کلاً جواب نمی‌ده |
| **فکر** | «خراب شد؟» |
| **احساس** | نگرانی (۳)، که با پیام فریز آروم می‌شه |
| **درد** | ترس از صفر شدن زنجیره، که ممکنه به دروغ یا جواب ندادن ختم بشه |
| **فرصت** | **حالت الف:** همون لحظه: «ممنون که صادق بودی. یکی از فریزهات زنجیره‌ت رو نگه می‌داره.» (D-052) و انتخاب اختیاری دلیل. **حالت ب:** صبح: «دیروز جواب ندادی؛ یکی از فریزهات زنجیره‌ت رو نگه داشت.» |
| **ویژگی دیدیت** | فریز خودکار برای «خیر» و بی‌پاسخ (D-023، D-040)؛ XP ‎+۴ برای «خیر» |
| **شاهد** | ۲۴٪ «خیر» صادقانه رو به حفظ زنجیره مشروط کردن |

### ۱۰. شکست و برگشت

| | |
|---|---|
| **کار آرش** | فریزهای ماه تموم شدن؛ یک روز دیگه «خیر» یا بی‌پاسخ؛ زنجیره صفر می‌شه |
| **فکر** | «حالا که خراب شد ...» |
| **احساس** | **ناامیدی (۱)**، پایین‌ترین نقطه‌ی سفر |
| **درد** | اثر «حالا که خراب شد»؛ انرژی برگشتن نداره |
| **فرصت** | زنجیره‌ی شکسته کم‌رنگ؛ **بهترین زنجیره و پایبندی پررنگ** («۱۸ روزی که ساختی سر جاشه»)؛ امتیاز بازگشت ‎+۳ با اولین «بله»؛ بعد از ۳ روز، وضعیت «در حال لغزش» با پیشنهاد کوچیک کردن هدف؛ دعوت به شروع تازه در شنبه یا اول ماه |
| **ویژگی دیدیت** | D-045، امتیاز بازگشت (D-004)، «در حال لغزش» (D-034)؛ حالت خواب‌آلود کرکتر |
| **شاهد** | ۳۰٪ در گذشته بعد از یک روز جا انداختن کلاً رها کردن |

### ۱۱. مدال ۲۱، مدال ۳۰ و ماه تازه (روز ۲۱ تا ۳۰+)

| | |
|---|---|
| **کار آرش** | دوباره زنجیره می‌سازه؛ اول ماه شمسی دو فریز تازه می‌گیره |
| **احساس** | **اعتمادبه‌نفس (۴ تا ۵)** |
| **فرصت** | تمدید فریز به‌عنوان «شروع تازه»؛ مدال‌ها؛ کرکتر تازه (سطح ۸ حدود هفته‌ی ششم) |
| **ویژگی دیدیت** | تمدید ماهانه‌ی فریز (D-034)؛ مدال ۲۱ و ۳۰ |
| **بعدش** | مدال ۶۶ روز («این دیگه یه عادته») و پیشنهاد کم کردن یادآوری (D-045) |
