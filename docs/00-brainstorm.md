# برین‌استورم اولیه

> این سند ثبت ایده‌ی اولیه‌ست و به همون شکل نگه داشته شده. نام محصول بعداً به «دیدیت» (Didit) تغییر کرد (D-028).

## ایده‌ی اولیه

| | |
|---|---|
| **نام** | از خودت بپرس / Ask Yourself |
| **موضوع** | نظم فردی و ساختن عادت جدید |
| **جامعه‌ی هدف** | کسانی که می‌خوان در کارهای مشخصی مثل ورزش نظم ایجاد کنن |
| **شعار** | تمام چیزی که نیاز داری نظمه |
| **مدل درآمد** | اشتراک درون‌برنامه‌ای |

### فلوی اولیه

1. **آنبوردینگ و ثبت‌نام**
2. **انتخاب دسته‌بندی** تا سه سطح، مثلاً: ورزش ← ورزش‌های هوازی ← دویدن. کاربر می‌بینه چند نفر دیگه در هر دسته فعالن.
3. **ساخت سؤال شخصی:** متن آزاد با پیشنهاد هوش مصنوعی، مثلاً «امروز ورزش هوازی انجام دادی؟». پاسخ فقط بله یا خیره.
4. **تعیین ساعت یادآوری روزانه،** مثلاً ۱۸:۴۵. اگه کاربر جواب نده، یادآوری دوره‌ای تکرار می‌شه. کاربر می‌تونه داخل اپ هم جواب بده.

### قوانین اولیه

- **پاسخ مثبت:** امتیاز مثبت (مثلاً ‎+۵). استمرار، امتیاز نظم اضافه داره.
- **پاسخ منفی:** زنجیره می‌شکنه و امتیاز منفی می‌گیره. تکرارش امتیاز بی‌نظمی داره.
- **بی‌پاسخ تا پایان روز:** زنجیره می‌شکنه و امتیاز منفی می‌گیره.
- **فریز:** تا ۲ بار در ماه، روز بی‌پاسخ نادیده گرفته می‌شه. هر ماه تمدید می‌شه.
- **مدال:** برای رسیدن به آستانه‌های استمرار (۲۰، ۳۰، ۶۰ روز و ...)
- **رنکینگ:** کاربر جایگاه خودش و بقیه رو در زیردسته‌هاش می‌بینه.
- **صفحه‌ی اصلی:** سؤال‌های کاربر با آمار کوتاه از وضعیت استمرار
- **پایان عادت:** امکان آرشیو کردن سؤال

## تحلیل

### جمع‌بندی

ایده مفیده، ولی ساختار پایه‌ش (ردیابی عادت با استریک) جدید نیست. رقبایی مثل Habitica، Streaks، Loop و Fabulous وجود دارن و منطق استریک Duolingo هم همینه.

**عوامل تمایز:**
1. قالب «سؤال از خود» به‌جای چک‌لیست
2. جامعه‌ی دسته‌بندی‌شده
3. فارسی‌اول بودن

**بزرگ‌ترین ریسک‌ها:**
- ماندگاری کاربر
- صداقت پاسخ‌ها وقتی رنکینگ وجود داره

### نقاط قوت

1. **قالب سؤالی پشتوانه‌ی علمی داره.**
   - اثر سؤال-رفتار (Question-Behavior Effect): پرسیدن درباره‌ی یک رفتار احتمال انجامش رو بالا می‌بره.
   - پژوهش Senay و همکاران (۲۰۱۰): پرسیدن «آیا انجامش می‌دم؟» عملکرد بهتری داشت تا گفتن «انجامش می‌دم».
2. **پاسخ بله/خیر ساده‌ست** و کار روزانه چند ثانیه طول می‌کشه.
3. **مکانیزم‌های امتحان‌شده:** استریک، فریز و مدال
4. **اثبات اجتماعی (Social proof):** دیدن بقیه‌ی کسایی که همین مسیر رو می‌رن

### ریسک‌ها و پیشنهادها

| ریسک | پیشنهاد |
|---|---|
| رنکینگ روی پاسخ‌هایی که خود کاربر اعلام می‌کنه راه تقلب رو باز می‌کنه | رنکینگ با درصد پایبندی، گروه‌های کوچک دوستانه، و در آینده تأیید خودکار با Google Fit یا Apple Health |
| جریمه‌ی سنگین باعث رها کردن یا دروغ گفتن می‌شه | «خیر» صادقانه جریمه‌ی کمتری از بی‌پاسخ داره؛ امتیاز بازگشت؛ وضعیت ملایم «در حال لغزش» به‌جای امتیاز بی‌نظمی |
| همه‌ی عادت‌ها روزانه نیستن | انتخاب روزهای هفته |
| شروع سرد: «۳ نفر در این دسته» حس اپ خالی می‌ده | نمایش عدد فقط بالای یک آستانه، یا جمع زدن در سطح بالاتر دسته‌بندی |
| «پایان روز» تعریف روشنی نداره | مهلت پاسخ بعد از یادآوری و مدیریت منطقه‌ی زمانی |
| یادآوری‌های تکراری آزاردهنده می‌شن | سقف ۲ تا ۳ یادآوری مجدد، قابل تنظیم |

### ایده‌های تکمیلی

- **پاسخ مستقیم از نوتیفیکیشن** (دکمه‌ی بله/خیر) و ویجت صفحه‌ی اصلی گوشی
- **پرسیدن دلیل بعد از «خیر»** برای ساختن بینش، مثلاً «معمولاً پنجشنبه‌ها جا می‌زنی»
- **مدال‌ها:** ۷، ۲۱، ۳۰، ۶۶، ۱۰۰ و ۳۶۵ روز. پژوهش Lally و همکاران (UCL) میانگین شکل‌گیری عادت رو حدود ۶۶ روز نشون داده.
- **کارنامه‌ی آرشیو:** گواهی قابل اشتراک بعد از پایان یک عادت
- **پیشنهاد سؤال:** اول با قالب‌های آماده‌ی هر دسته، بعداً با هوش مصنوعی

### پیش‌نویس سیستم امتیاز

اعداد پیشنهادی‌ان و در مرحله‌ی ۲ نهایی می‌شن.

| رویداد | نتیجه |
|---|---|
| پاسخ «بله» | ‎+۵ |
| پاداش نظم | از روز ۷ استریک ‎+۱ اضافه، از روز ۳۰ ‎+۲ اضافه |
| پاسخ «خیر» | ‎−۲ و شکستن زنجیره |
| بی‌پاسخ تا پایان مهلت | ‎−۵ و شکستن زنجیره، مگر با فریز |
| «بله» در روز بعد از شکست | ‎+۳ امتیاز بازگشت |
| فریز | ۲ عدد در ماه، فقط برای روزهای بی‌پاسخ |

### مدل درآمد اولیه

حلقه‌ی اصلی اپ پشت پرداخت نمی‌ره.

- **رایگان:** یک یا دو سؤال فعال، استریک، مدال‌های پایه، فریز ماهانه
- **اشتراک:** سؤال نامحدود، آمار و بینش پیشرفته، پیشنهاد هوش مصنوعی، فریز اضافه، چالش گروهی، تم‌ها
