# کرکترهای کاندید

**وضعیت:** ذخیره‌شده برای بررسی (D-037) · **مرحله:** تصمیم نهایی در مرحله‌ی ۷ (دیزاین سیستم)

دو مجموعه‌ی پیکسل‌آرت که طراح محصول فرستاده. هر کرکتر جدا شده و به‌صورت PNG و SVG ذخیره شده، پیکسل‌به‌پیکسل مطابق فایل اصلی (اختلاف ۰٪). انتخاب کرکترها، نحوه‌ی استفاده و ترتیب باز شدنشون در مرحله‌ی دیزاین سیستم بررسی می‌شه.

| مجموعه | فایل اصلی | تعداد | شبکه | رنگ‌ها |
|---|---|---|---|---|
| [`set-a`](set-a/contact-sheet.png) | `cute-pixel-art-character-set-retro-2776485547.eps` | ۴۲ | تا ۱۶×۱۶ | ۱۶ رنگ (پالت DawnBringer 16) |
| [`set-b`](set-b/contact-sheet.png) | `cute-pixel-art-characters-retro-game-2776485545.ai` | ۴۲ | تا ۱۶×۱۶ | ۱۵ رنگ از همون پالت |

## ساختار هر پوشه

| مسیر | محتوا |
|---|---|
| `source/` | فایل اصلی طراح |
| `png/` | هر کرکتر روی بوم ۱۶×۱۶، یک پیکسل برای هر پیکسل طرح، پس‌زمینه‌ی شفاف |
| `svg/` | همون کرکترها به‌صورت مستطیل‌های SVG |
| `contact-sheet.png` | همه‌ی کرکترها با شماره، برای انتخاب |
| `report.json` | ابعاد هر کرکتر، نتیجه‌ی تطبیق و پالت |

شماره‌ها از بالا-چپ فایل اصلی، ردیف‌به‌ردیف شمرده می‌شن.

## یادداشت‌ها برای مرحله‌ی ۷

1. **لایسنس:** هر دو فایل از یک طراح («Dzhioeva Anastasiia») و ظاهراً از یک سایت فروش تصویرن. قبل از استفاده باید لایسنس خریداری‌شده بررسی بشه:
   - استفاده داخل اپ
   - استفاده در آیتم‌های پولی اشتراک
   
   این مجموعه‌ها انحصاری نیستن.
2. **ساختار:** کرکترها نیم‌تنه‌ان (سر و شونه)، نه بدن کامل ۳۲×۳۲ با قالب مشترکی که در D-035 فرض شده بود. وسیله‌های مشترک روی همه نمی‌شینن و انیمیشن‌ها به تکون، پلک و حالت چهره محدود می‌شن.
3. **موضوع (D-036: حیوان‌ها و موجودات):**
   - **set-b** حیوان‌های بیشتری داره، مثل روباه، خرگوش، گربه، موش، پرنده و حشره.
   - **set-a** بیشتر آدم و شخصیت فانتزیه.
4. **لحن برند:** چند کرکتر اسکلت یا ترسناکن و با برند گرم جور نیستن.
   - **set-a:** ۰۲، ۱۱، ۱۸، ۲۳، ۲۸، ۳۹
   - **set-b:** ۳۸، ۴۱
5. **ریسک حقوقی:** کرکتر ۰۶ در set-a خیلی شبیه Creeper در Minecraft‌ه.
6. **رنگ:** تبدیل خودکار به پالت برند ممکنه، ولی کرکترهای تیره جزئیات رو از دست می‌دن و نگاشت دستی لازم دارن.

## ساختن دوباره

```bash
python3 tools/characters/extract_sheet.py <فایل اصلی> <پوشه‌ی خروجی> --prefix <پیشوند>
```

نیاز به Ghostscript (`gs`) و poppler (`pdftocairo`) داره.
