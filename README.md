# از خودت بپرس | Ask Yourself

> تمام چیزی که نیاز داری نظمه.

اپلیکیشن موبایل برای نظم فردی و ساختن عادت‌های جدید. کاربر هر روز یک سؤال بله/خیر از خودش می‌پرسه («امروز دویدی؟»)، زنجیره‌ی نظمش رو حفظ می‌کنه، امتیاز و مدال می‌گیره و می‌بینه چند نفر دیگه در همون مسیر هستن.

## وضعیت پروژه

پروژه در **مرحله‌ی ۲ (هویت بصری)** و **مرحله‌ی ۳ (تفکر محصول)** به‌صورت موازی است: طراح محصول لوگو و پالت رو طراحی می‌کنه و هم‌زمان تفکر محصول جلو می‌ره. مرحله‌ی ۱ (استراتژی محصول) تمام شده. نقشه‌ی کامل در [docs/00-roadmap.md](docs/00-roadmap.md).
