# دیدیت | Didit

> تمام چیزی که نیاز داری نظمه.

اپلیکیشن موبایل برای نظم فردی و ساختن عادت‌های جدید. کاربر هر روز یک سؤال بله/خیر از خودش می‌پرسه («امروز دویدی؟»)، زنجیره‌ی نظمش رو حفظ می‌کنه، امتیاز و مدال می‌گیره و می‌بینه چند نفر دیگه در همون مسیر هستن.

## وضعیت پروژه

پروژه در **مرحله‌ی ۷ (دیزاین سیستم)** است. مرحله‌های ۱ (استراتژی محصول)، ۲ (هویت بصری)، ۳ (تفکر محصول)، ۴ (تحقیق)، ۵ (آنالیز رقبا) و ۶ (تفکر طراحی) تمام شدن. بعد از این مرحله، دیزاین (۸). نقشه‌ی کامل در [docs/00-roadmap.md](docs/00-roadmap.md).
